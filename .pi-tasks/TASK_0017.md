- The `.omwscripts` manifest loads `init.lua` as `GLOBAL` and `load-db.lua` as `LOAD` — LOAD fires during content loading, so load-db.lua's module table is cached and available when init.lua runs in GLOBAL.

- `load-db.lua` is the single handler for all `openmw.content` usage in the mod — `ingredient-detect.lua` also imports it but that's out of scope for this refactoring.
